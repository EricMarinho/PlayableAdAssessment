# Visual Iteration: Dark Magical Theme (Backup Branch)

Before pivoting to match Scrambly's bright daytime UA marketing assets, this project was prototyped using a high-contrast **Deep Ink (`#201338`)** dark mode aesthetic. 

## 🌙 Key Characteristics of this Version:
- **Background:** Deep cosmic purple-black tone with sharp drifting starfield particles.
- **Contrast:** Neon-glow effects (`box-shadow`) applied to the timer pills and progress bars using Orange (`#F58324`) and Purple (`#7845D8`) highlights.
- **Aesthetic:** Designed for an immersive, arcade-style midnight feel.

> **Note:** This version is preserved in the Git branch `backup-dark-theme` and serves as a testament to design adaptability during the development lifecycle.
